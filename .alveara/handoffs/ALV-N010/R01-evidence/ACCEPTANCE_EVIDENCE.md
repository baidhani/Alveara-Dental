## Required tests named in the prompt
- Template-version tests — `FormTemplateVersionTests`.
- Signed snapshot immutability — `SignedFormSnapshotTests`.
- Duplicate-submit/idempotency — `FormSigningTests` (duplicate/simultaneous/key tests) and the HTTP and browser replays.
- Authorization/audit tests — `FormsApiTests` (per-role access, CSRF, void permission) and the audit assertions in the signing, lifecycle and template classes.
- Interrupted-signature test — `An_interrupted_signature_leaves_a_plain_draft…`, `A_cancelled_request_never_commits_a_partial_signature`, the UI "outcome unknown" test and the walkthrough INTERRUPTED SIGNATURE test.

## Failure paths named in the prompt
Template changes during active completion (draft stays on its version; newer version offered; move carries answers) · Signature interrupted (atomic save; same-key retry) · Signer identity/relationship missing (400 with per-field messages; form stays a draft) · Duplicate submit (above) · Attempt to alter a signed snapshot (application refusal, database refusal, no edit path for a signed form).

## ALV completion contract
Tests pass (above); no secrets or real PHI (the walkthrough used invented names; the package scan is recorded in `MANIFEST.json`); audit coverage (above); concurrency (row versions on templates, drafts and voids; stale = shared 409); idempotency (signing, start, void, template save); measurement (`form.signed`); accessibility (14 real-browser axe scans, light + dark, and component axe tests); the handoff discloses decisions, limitations and the carried-forward findings.
