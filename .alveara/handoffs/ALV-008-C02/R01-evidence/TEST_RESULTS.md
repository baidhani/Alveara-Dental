## Risk declaration (Binding Testing Cadence Notice, 2026-10-13)
**This story is HIGH RISK**, as the notice itself says for ALV-008-C02. It changes a migration and schema (`AddCompletionAdoption`: a column, a check and trigger 51172), the authoritative completion workflow and its idempotency and concurrency rules, billing integration (adoption calls the charging contract; one change to the document reprint's snapshot), odontogram behaviour (adoption moves a finding), retired production routes, and parent-test infrastructure (a test-only fixture and a real-browser seed replace the removed code in more than a dozen test files). Beyond the notice, the whole real-backend walkthrough sweep (25 runs) was run as well, because the story retires the completion path those walkthroughs use.

## The one pre-existing, unrelated failure in the sweep
The clinical companion walkthrough (`clinical-companion-real-backend.spec.ts`, step TRUST) asserts that the audit-log text does not contain the substring `190` (the sample of clinical values it checks for). The spec names a note template with its own `Date.now()` stamp (`SOAP visit 1791901737808`), and during roughly 2.8 hours today that stamp contains `190`. The failure message shows the matched text is the template name. Rerun with only the spec's `Date.now` shifted by 12,000,000 ms (`artifacts/regression/shift_clock.js`, NODE_OPTIONS preload): 9 of 9. Neither the spec nor anything it exercises was touched by this story. Not fixed here (scope lock).
