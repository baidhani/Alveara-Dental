## Required tests (from the prompt)
- Alert lifecycle/history tests — `SafetyAlertServiceTests`, `SafetySchemaTests`.
- Acknowledged-vs-resolved test — item 3.
- Clearance workflow tests — `ClearanceServiceTests`, browser `CLEARANCES`.
- Permission/audit tests — `SafetyApiTests` role matrices, `ClinicalPermissionTests`, service audit tests (PHI-free, audit failure stores nothing), browser `TRUST` and `ACCESS`.
- Downstream safety-context service test — `SafetyContextServiceTests`.
- Flow-board safety-indicator authorization/minimization test — `SafetyApiTests` board tests, `FlowBoardSafety.test.tsx`, browser `LIVE BOARD`.

## Failure paths required by the prompt
Conflicting/stale safety data (row version 409, `alert_changed` for a stale acknowledgement, `needsAttention` when a source item changed — service, API, UI banner with in-place reload, real browser); alert source missing (`source_required`, screen and API); resolve without a reason (`reason_required`, screen and API); permission denied (403 matrices, no controls drawn); supporting document not yet available (`documentPending`, "Supporting document not yet attached", attach later).
