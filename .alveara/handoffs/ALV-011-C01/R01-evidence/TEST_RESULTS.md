## Run notes (honest account)
- **A regression run on a stale binary was discarded.** After the authorization mutation checks I restored the source but did not rebuild, then started a `--no-build` regression run: it reported exactly the two failures the mutation causes. It was stopped, the solution rebuilt, and everything counted here was run on binaries built from the final sources (the full run above started right after a verified rebuild).
- **Mistakes of mine found along the way** (none in a passing state): test helpers that did not compile (guessed names), a helper that never stopped at the current state, tuples of arrays compared by reference, a test using a "past" date that was in the future, a wrong `ApiError` argument order, a real-backend spec that expected 200 where signing returns 201 and one booked past the provider's hours, the new spec missing from the default config's ignore list, and a draft test that swallowed assertion failures with `.catch` (removed and rewritten). Only the final complete runs are counted.
- **Product defects the tests found** (fixed): cancelling or no-showing a *confirmed* appointment broke the database check (the flow is now reset, the Confirmed event kept); the database's case-insensitive collation accepted `completed` in lower case (the check is now case-sensitive); the race tests did not detect a missing lock (above); the board's first screenshots showed unreadable waiting times and wasted width (fixed).
- Not re-run (unaffected): Gate A A1/A9 specs and the recovery-key timing spec.
