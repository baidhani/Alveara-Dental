# ALV-016-C01 R01 - Demo evidence

The visible workflow is demonstrated un-mocked: a real Chromium against the real Vite proxy, the real `Alveara.Api` and a real LocalDB (a fresh database per run), one signed-in browser session per role (a dentist with a staff profile, a hygienist, a front-desk user, and an administrator for the audit log). Spec `src/alveara-client/e2e/prescription-workflow-real-backend.spec.ts` (**15 of 15**), run with `sh run_e2e.sh <fresh db> playwright.prescription-workflow.config.ts PRESCRIPTION_WORKFLOW_E2E_OUT <dir>` (how: `docs/testing/REAL_BACKEND_E2E.md`). Axe (WCAG 2.0 A and AA, light and dark) found **0 blocking violations** on the composer, the incomplete draft, the confirmation, the print preview and the changed-list alert (`walkthrough/prescription-workflow-evidence.json`). Patients are synthetic (Ann Alder, Bo Brandt); no real PHI.
