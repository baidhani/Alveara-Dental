## The plan's required tests
- Original STORY-018 import regression: criterion 1.
- Dry-run/no-write test: criterion 2.
- Malformed/partial batch tests: `CsvParserTests`, `ImportIntakeServiceTests`, `ImportCommitTests.Valid_rows_only_leaves_the_rejected_skipped_and_unresolved_rows_where_they_are_and_says_so` (criterion 3).
- Duplicate-patient integration: criterion 4.
- Scheduling-conflict import integration: criterion 5.
- Opening-balance ledger/provenance test: criterion 6.
- Restart/retry/idempotency test: criterion 7.
- Batch reconciliation test: criterion 8.

## Failure paths in the plan
Malformed or oversize file (`ImportIntakeServiceTests`, `CsvParserTests`; refused, nothing stored); unknown or duplicate columns and an invalid mapping (`ImportPatientDryRunTests.A_bad_or_missing_mapping_is_refused_with_its_problems_and_a_dry_run_needs_a_confirmed_one`); invalid references (a row that names no patient, provider, operatory or type is rejected with a fixed message); duplicate-patient candidate (criterion 4); appointment conflict (criterion 5); invalid opening balance or currency (`ImportBalanceDryRunTests`); partial batch errors (the policy: all-or-nothing for patients, valid rows only for all kinds); interruption during commit and retry after an uncertain result (criterion 7). Security: `BulkImportData` required (`BulkImportPermissionTests`; the four newest calls refused to anonymous callers and roles without it, `ImportSlice6ApiTests`); balances also need `ManageBilling` (`ImportBalanceCommitTests.All_or_nothing_is_refused_and_a_caller_without_manage_billing_is_refused_before_anything_changes`); file contents are never logged; the error report neutralises spreadsheet formulas.

## Stated as untested
The rollback guards (errors 51263, 51267, 51268); restoring a backup that contains import files; ambiguous and merged patients in a file; a start time that passes into the past between the dry-run and the commit (not testable with the real clock); a conflict or a 503 leaving a row Valid; a non-Administrator holding `BulkImportData` without `ManageBilling` over HTTP (tested at service level and in the walkthrough); a half-done retry (simulated with a pre-made ledger entry); stray-file removal on a real disk in the walkthrough. The error-report test accepts either Skipped or Unresolved for the classification of a duplicate row.
