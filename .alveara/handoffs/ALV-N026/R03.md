## What R03 changes
The print helper's detection of how the server PDF reaches the user. R02's helper missed a tab that closes and a download on the new tab, which is the likely headless-Chromium behaviour for a tab sent to a PDF. Every assertion of the review's item 2 is unchanged:
- the click issues on the server and fetches the PDF;
- the response is a real PDF;
- `window.print()` is never called;
- the PDF contains no app address or raw detail;
- a tab or a download is accepted.

The helper now also records where the PDF arrived, so the run itself shows the cause.
