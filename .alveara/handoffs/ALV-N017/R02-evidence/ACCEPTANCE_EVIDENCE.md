1. **`ManagePermissionGrants` added; defaults stay in `PermissionMatrix`; Admin holds everything; `Unassigned` nothing; with no rows effective equals defaults for every enum-derived cell (not hard-coded).** `PermissionRegistryTests` (Admin all, Unassigned none, the new permission); `PolicySnapshotBuilderTests.With_no_stored_rows_every_cell_equals_the_code_default_generated_from_the_enums` (every role times every permission, computed from the enums); `EffectivePermissionServiceTests.Every_cell_decision_equals_the_code_default_when_there_are_no_rows`; `PermissionPolicyStoreTests.The_first_read_finding_no_rows_gives_the_code_defaults`.
2. **Versioned overrides, immutable history, delegations, policy state; names not ordinals; committed registry.** `PermissionPolicySchemaTests` (13: append-only history 51204, version forward by one 51205, one state row, effect/kind/reason constraints, unique cells, default delegations, wrong values representable, rollback guard 51206, one-transaction rollback); `PermissionRegistryTests` (enum and registry must agree, no retired name reused, names exact and never numbers).
3. **Every decision through one seam; guards.** The attributes, the four controllers, the consumer and `AuthController` use `IEffectivePermissions`; `AuthorizationArchitectureTests` (nothing but the matrix and the builder reads the static matrix; the two attributes decide through the seam and no other filter reads the role claim; the inventory of 270 or more `RequirePermission` sites and one `RequireAnyPermission` cannot shrink; account role and disabled state written and accounts deleted only by `AccountService`); negative control N15.
4. **Protected permissions Admin-only, non-grantable, non-delegable; the two assignable ones never delegable; no policy-write API.** `PermissionRegistryTests` (protection sets and rules); builder tests (every protected permission as a stored grant is invalid and puts the role in repair; delegation classes); `PermissionPolicyPipelineTests.A_stored_row_can_never_grant_a_protected_permission...` and `No_combination_of_stored_grants_lets_a_non_administrator_reach_a_protected_endpoint` (ManageRoles, IssuePasswordResets, ManageUsers refused with every grantable permission granted); no controller route writes an override or a delegation (the only write is the invalid-row repair).
5. **Target rules and refuse self-disable; `GET /api/auth/users` unchanged.** `AccountSafetyTests` (administrator target refused on all four actions; roles holding a permission the actor lacks refused; subset roles, a peer and an unassigned account allowed; self-disable refused and own-session revoke allowed; administrator actors unrestricted; a change to the holder's grants changes the next outcome; concurrent refused requests; audit of ids and the rule only); `PermissionPolicyPipelineTests` (through the API, 5 refusals audited, nothing changed; `The_user_list_has_the_same_status_and_body_for_every_role_before_and_after_the_two_assignable_permissions_are_granted`); negative controls N11 to N13; walkthrough TARGET RULES.
6. **Last enabled administrator across role change, disable, delete-equivalents, raw SQL and bulk updates; lock plus trigger; stable, auditable, no partial change.** `AccountSafetyTests` (only administrator refused for both operations; two administrators demoting, disabling and mixing at once leave exactly one; twenty mixed attempts across three leave at least one; raw SQL update, bulk update and delete refused by trigger 51207; removing one of two allowed; bootstrap and ordinary updates unaffected; a busy lock waits 5 s, changes nothing and the same request then works; refusals audited); `PermissionPolicyPipelineTests` (409 `last_admin` through the API); walkthrough LAST ADMINISTRATOR; negative controls N10 and N14. Deletion: no application path deletes an account (architecture test), the trigger and the history foreign key refuse it in the database.
7. **Versioned immutable snapshot protocol; one transaction for write, history, audit and version; version bracketing; 60-second stale allowance then 503; never defaults while overrides may exist; next-request revocation across two instances.** `PermissionPolicyStoreTests` (warm read costs one version read; a changed version is served from the new snapshot; single flight; bracket detects a racing writer; never-stable read fails closed after three attempts; 60 seconds counted from the last confirmation; no snapshot plus unreadable store denies; slow reload not waited for beyond 2 s); `PermissionPolicyHealthTests.When_the_audit_entry_cannot_be_written_the_whole_repair_is_rolled_back` (row, history, version and audit change together or not at all); `PermissionPolicyTwoHostTests` (two hosts, 200 interleaved revoke and revert iterations applied to the very next request on both; a grant reaches the other host; an open writer transaction invisible then visible whole; a writer toggling under a stream of readers never produces a torn read; an injected store outage serves the old snapshot for at most 60 seconds then 503 and recovers); negative controls N6, N7, N8.
8. **Invalid persisted data never restores access; repair APIs; health visibility; PHI-safe logs.** Builder tests (every invalid class); service and pipeline tests (repair-required 403, degraded 503 with the administrator unaffected); `PermissionPolicyHealthTests` (health lists each invalid row with raw values; reported once per row version; log holds counts only; the repair needs a reason and the shown row version, refuses a valid row, an unknown row, a stale row, and a missing token; double removal is a quiet 404; concurrent removals produce one); negative controls N1 to N5, N9; walkthrough INVALID DATA.
9. **Existing 403 bodies and ordinary access preserved.** `PermissionPolicyPipelineTests` (14 module samples: default access unchanged, the 403 body `permission_denied` with `required` unchanged after a stored revoke); 788 `*ApiTests` passed through the seam; STORY-010 and ALV-N015 walkthroughs unchanged.
