## Architecture / schema / API / UI / security / config / measurement changes (this attempt only)
- **Schema:** migration `20261008144126_AddProcedureProvenanceRule`: one check constraint and one trigger (51083, 51084; **51085 and up are free**). It is a new migration; the R01 migration `AddProcedureCatalog` is not edited, because attempt history is immutable and the R01 migration may already be applied in development databases. `Down` drops the trigger and the constraint (verified on a scratch database). On a database that already holds a non-local version with no source, the new constraint would not block (it checks blank text, not missing sources) and the trigger only judges new inserts; no database has ever held a procedure outside tests, and nothing was deployed.
- **API:** no new endpoint. A CDT or external create or revise without a source is now a `400 validation_failed` with `fieldErrors.sourceName`.
- **UI:** none changed (the add form already required a source for every non-local code system); a unit test and a browser step now prove it for CDT.
- **Security / config / measurement events:** none.
