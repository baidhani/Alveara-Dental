## Development notes (process honesty)

- Three of my own tests failed on first run and were fixed *in the tests*, not the product: an xUnit culture-sensitive `DoesNotContain` ignored control characters in `"PK\u0003\u0004"` (switched to ordinal); a retention test ran its own retention too early (marked the oldest verified before later backups); and tests sharing one database were polluted by earlier tests' MFA secrets (protected with another test's key ring) — the reset helper now clears them. One product-visible change came from the API test run: a failed *run* now returns 500 with a stable code (it had returned the 400 of the internal exception).
- A first, smaller corruption of the database media in the "damaged database" test hit unused pages and was not detected; the test now corrupts 64 KiB at three places, which SQL Server's checksum reliably rejects.
