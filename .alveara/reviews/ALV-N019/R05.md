## Required correction

`RealMigrationInventoryTests.An_entry_listed_as_calling_the_migrator_still_does_and_each_entry_uses_the_fixture_of_its_group()` changes its source lookup to:

```csharp
Classes().GroupBy(c => c.Name).ToDictionary(g => g.Key, g => g.First())
```

That is not a sound fix for a partial class. `Directory.GetFiles` does not give
this guard a contractual file ordering. Selecting the first fragment can inspect
`TestDatabaseFixture.cs` on one machine and `TestDatabaseFixture.Retry.cs` on
another, hiding whichever fixture behavior lives in the other fragment.

Replace this with a deterministic composite source for each partial class used
by the assertion: retain the class name and combine the text of **all** matching
fragments before applying `MigratorCall`, `TemplateFixtureUse`, or
`RealFixtureUse`. Do not suppress or exclude the partial fixture from the
inventory guard. Add a focused assertion proving the lookup considers both
fragments (or one that would fail if either fragment were omitted).

Re-run the five inventory tests and the existing source-scanning sweep after
that correction. Preserve the R04 Stage 2 result and the R05 focused evidence
as immutable attempt history.
