## Required focused corrections

### C01-1 — Prove the required accessibility modes

The approved briefing requires 200% zoom and forced-colours coverage. R01 explicitly discloses neither was exercised. Add focused browser evidence that:

- at 200% zoom, the sign-in screen remains keyboard-operable with no horizontal scrolling or obscured sign-in/footer content; and
- in forced-colours/high-contrast mode, the decorative background is safely suppressed or overridden while the solid panel, visible focus, labels, form, status/error state, and notice remain readable and operable.

Use the same representative viewport/theme coverage appropriate to the existing login presentation spec. This must be real browser evidence, not only CSS reasoning.

### C01-2 — Force the select-versus-inactivate concurrency race

The migration triggers are a useful database backstop, but direct SQL trigger tests do not prove the two competing application transactions behave correctly. Add a deterministic concurrent test with a synchronization barrier that races selection of an added image against inactivation of that same image. Prove the final persisted state never selects an inactive image, exactly one conflicting operation receives the defined conflict/refusal, and the associated audit/history remains truthful. Do not relax, remove, or replace the trigger safeguard.

### C01-3 — Make the 30-active-image limit concurrency-safe

`AddImageAsync` and reactivation each read the active count before writing. Two requests observing 29 can both succeed, producing 31 active added images. That violates the approved server-validated, concurrency-safe catalog limit.

Enforce the cap at the database/transaction boundary (for example, a narrowly scoped trigger or serialized guarded operation that covers both insert and reactivation), map its refusal to `background_catalog_full`, and add deterministic concurrent tests for both two uploads at 29 and upload/reactivation at 29. The tests must prove the final count is never above 30 and that file cleanup leaves no orphan derivative from the refused upload.
