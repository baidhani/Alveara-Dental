## Decision on the requested design change

The 13 named rollback classes **may start from a template clone**. This is an approved refinement of R01’s inventory rule, subject to the controls already present in R02:

- the template itself is still created from an empty database by real EF migrations;
- `MigrationTests`, `MigrationUpgradeTests`, and the four fixture-behavior classes remain on the real create-and-migrate path;

The measured 250-test comparison (666 seconds on the former real path, 184 seconds on clones) supports this change. The shipped prefetch experiment was correctly reverted after showing no reliable gain and a cleanup risk.

## Blocking finding

**ALV-N016-R02-01 — a material production billing-concurrency defect is now proven and must be corrected before any new formal regression.**

The accidental full backend run exposed `KeyNotFoundException` from `BillingService.Ledger.MathAllocations` during two simultaneous payment operations. `LoadLedgerAsync` reads entries, allocations, and releases in separate queries, permitting a committed allocation to appear after the entries query’s snapshot. The required concurrent operation therefore returns an implementation exception instead of the intended `ConcurrencyConflictException`.

This is not an acceptable exception to the frozen zero-failure Stage 2 criterion and must not be waived because it was observed only once. The affected production owner is **ALV-007-C01 — Financial Ledger, Charges, Payments, Adjustments, and Guarantor Foundation**, not ALV-N016.
