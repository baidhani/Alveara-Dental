# STORY-017 negative controls

A negative control breaks one piece of the code on purpose, rebuilds, runs the focused tests, and expects at least one to fail. A control that survives means a missing test (or a dead condition). Each script restores the file byte for byte afterwards. Raw records are kept in the session scratch folder; this is the summary.
